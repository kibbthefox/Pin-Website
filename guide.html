Guide

There are a few things you should know when asking me to make a pin.

1. Deals
- As it says on the homepage, 1 dollar = 1 pin and 2.50 dollars = 3 pins.

2. Image Resolution
- When submitting please provide an image with good quality or else it will come out bad!

3. Image Space
- When making a pin, you need a little bit of extra space around the edges of the images so it can fully wrap around the pin. So please submit a photo that has a bit of extra space around the edges.

4. Warranty
- For every pin, if it breaks, it gets one free remake.

If you have any questions, message me!
